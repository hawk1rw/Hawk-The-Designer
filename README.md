# Creative Designer Portfolio

A modern, responsive portfolio website for showcasing:

* Logo Design
* Flyer & Poster Design
* Banner Design
* Video Intros
* Branding Projects

Built using only **HTML, CSS and JavaScript**.

---

## 📁 Project Structure

```text
portfolio/
│
├── index.html
├── style.css
├── script.js
│
├── images/
│   ├── logo1.jpg

│   ├── banner1.jpg
```

---

## 🚀 Getting Started

No installation or server is required.

### 1. Download or clone the project

Place all project files inside one folder.

### 2. Add your designs

Put your images inside:

```text
images/
```

Put your video intros inside:

```text
videos/
```

### 3. Open the website

Double-click:

```text
index.html
```

The website will open in your browser.

---

## 🖼️ Adding Portfolio Images

Replace the sample portfolio blocks with your real designs.

Example:

```html
<div class="project-image">

    <img
        src="images/logo1.jpg"
        alt="Logo Design Project"
    >

</div>
```

Make sure the filename matches the actual image filename.

For example:

```text
images/logo1.jpg
```

must match:

```html
src="images/logo1.jpg"
```

---

## 🎬 Adding Video Intros

You can add your video files to:

```text
videos/
```

Example:

```html
<video
    src="videos/intro1.mp4"
    controls
    muted
    playsinline>
</video>
```

## ✏️ Customizing Your Information

Open `index.html` and replace:

```text
YOUR DESIGN
```

with your actual designer or business name.

Also replace:

```text
Your Name
```

with your name.

## 📱 WhatsApp

Find this:

```html
<a
    class="btn primary"
    href="https://wa.me/250000000000">
    WhatsApp Me
</a>
```

Replace:

```text
250000000000
```

with your WhatsApp number.

### Important

Use the international format without:

* `+`
* spaces
* brackets
* dashes

Example:

```text
2507XXXXXXXX
```

---

## 📧 Email

Find:

```html
<a
    class="btn secondary"
    href="mailto:your@email.com">
    Email Me
</a>
```

Replace:

```text
your@email.com
```

with your real email address.
